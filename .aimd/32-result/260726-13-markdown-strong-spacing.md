# Markdown strong 뒤 실제 공백 결과

- 일자: 2026-07-26
- 대상: `web/` LLM Markdown 응답
- 요청: 볼드 뒤 한글이 이어질 때 렌더러 우회가 아니라 실제 Markdown 공백을 포함

## 변경

- `**수치**로`를 `**수치** 로`로 정규화하는 공통 함수를 추가했다.
- LLM system prompt에도 닫는 `**` 뒤 한글이 이어지면 실제 공백을 넣도록 명시했다.
- 스트리밍 화면은 렌더 직전 정규화하고, 완료된 응답은 정규화된 문자열을 대화 이력에 저장한다.
- Markdown·JSON 내보내기와 후속 LLM 대화에도 공백이 포함된 응답을 사용한다.
- 기존 zero-width entity 삽입과 AST 제거 우회 코드를 삭제했다.

## 검증

- `**1.716→0.742ms(-56.76%)**로`가 `**1.716→0.742ms(-56.76%)** 로`로 변환되는 단위 테스트를 추가했다.
- 이미 공백이 있는 Markdown에는 중복 공백을 추가하지 않는 것을 확인했다.
- 일반 bold와 개선·회귀 semantic color가 실제 공백 뒤에도 정상 렌더되는 것을 확인했다.
- 전체 테스트 22개와 프로덕션 빌드가 통과했다.
