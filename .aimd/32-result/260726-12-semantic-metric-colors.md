# LLM 수치 개선·회귀 색상 결과

- 일자: 2026-07-26
- 대상: `web/` Markdown 분석 리포트
- 요청: 긍정적인 수치는 초록색 bold, 부정적인 수치는 빨간색 bold로 표시

## 기준

- 산술 부호만으로 개선·회귀를 정하지 않는다. duration 감소와 jank 증가처럼 지표별 방향이 다르기 때문이다.
- LLM이 지표 의미상 명확한 개선은 `**[개선] 수치**`, 회귀는 `**[회귀] 수치**`로 출력한다.
- workload 차이처럼 방향이 불확실한 값은 표식 없는 일반 bold를 사용한다.

## 렌더링

- `[개선]`·`[회귀]` 표식은 화면에서 숨긴다.
- 개선 수치는 초록색 800 weight, 회귀 수치는 빨간색 800 weight로 렌더링한다.
- 일반 bold와 citation 검증, GFM 표 안의 strong 렌더링은 그대로 유지한다.
- 리포트 상태 줄에 개선·회귀 색상 범례를 추가했다.

## 검증

- 개선·회귀·중립 수치가 각각 semantic class·일반 strong으로 렌더되는 server-side React 테스트를 추가했다.
- 한글 조사가 바로 붙는 colored strong에서도 표식과 경계 문자가 노출되지 않음을 확인했다.
- 전체 테스트 20개와 프로덕션 빌드가 통과했다.
