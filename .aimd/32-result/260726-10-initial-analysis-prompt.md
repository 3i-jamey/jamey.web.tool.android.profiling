# 첫 화면 분석 프롬프트 입력 결과

- 일자: 2026-07-26
- 대상: `web/` 캡처 입력과 자유 분석 흐름
- 요청: ZIP 비교 전 첫 화면에서 첫 LLM 프롬프트 입력

## 변경

- 캡처 선택 영역 위에 `첫 분석 요청` textarea를 추가했다.
- ZIP 파일 선택, trace 추출, fact pack 생성과 JSON fact pack 불러오기 중에는 입력 프롬프트를 초기화하지 않는다.
- 비교 완료 후 같은 값이 자유 분석의 첫 composer로 이어진다.
- `새 분석 대화`를 명시적으로 누를 때만 기본 프롬프트로 초기화한다.
- 비교 전·후 입력 요소에 같은 접근성 label을 사용한다.

## 검증

- 브라우저에서 첫 화면에 사용자 프롬프트를 입력하고 ZIP 두 개를 추출했다.
- 1000ms 비교와 979,697-byte fact pack 생성 후 첫 분석 composer에 입력 문자열이 그대로 유지되는 것을 확인했다.
- 전체 단위 테스트 18개와 프로덕션 빌드가 통과했다.
